# 玄幻/仙侠「长生苟道」可选风格插件

## 定位

这是一个题材限定、显式选择的质量插件，适用于：

- 凡人流
- 苟道流
- 系统流
- 长生流

它叠加在现有的网络小说质量基线上，重点改善读者体验中的短句网感、反差推进、资源积累和重复节拍变体；不替换世界观、人物设定、章节细纲、第三人称和内容安全约束。

默认不启用。普通玄幻升级流、史诗玄幻、都市题材即使没有选择插件，也不会得到这套规则。

## 来源与取舍

来源：用户提供的《系统赋我长生_写作模板.md》，以及项目既有的玄幻/平台质量基线。

保留的可迁移方法：

1. 用具体处境和后果表现长生/系统，而不是连续弹出面板或解释规则全集。
2. 用“表面平淡、实际占便宜或躲过风险”的反差制造爽感。
3. 同一节拍可以复用，但失败原因、人物反应、物件和结果必须变化，禁止段落复制。
4. 短句白描、少空泛总结，让动作和对白承担信息。
5. 苟道必须持续积累资源、信息、关系、身份或风险优势，不能把慢写成停滞。

不作为硬门禁的内容：均句长、对白比例、修辞密度和爽点词密度。这些只作为软验收目标，不能为了凑数字破坏自然阅读；标点也不设全局禁用清单，只治理整章高密度和模板化重复。

## Prompt 前置策略

启用插件后，生成前 Prompt 会优先注入：

- 首段用反差动作或判断立住声音；
- 长生/系统规则通过事件后果显露；
- 每章至少推进资源、信息、关系、身份或风险之一；
- 重复节拍必须改变变量；
- 系统提示内化，避免面板和数字播报刷屏；
- 不用“打脸/无敌/逆天”等词语堆砌爽感；
- 段首要有变化：不要让同一个两字人名机械占据大量段落开头；在不丢失第三人称限知的前提下，从动作、场景、物件、对白或他人反应切入，也不要把人名全部粗暴替换成“他/她”；
- 不禁用标点，只限制破折号、重复句式和工整排比的异常密度。

## 运行与验收

插件选择会写入作品元数据，并由 V7 运行时恢复。质量报告应同时关注：

- 重复段落率为零；
- 严格第三人称叙述通过；
- 系统弹窗、破折号和模板套话没有成片增长；
- 每章有可见状态变化和下一步压力；
- 同类节拍跨章有变量，不是复制粘贴；
- 插件未选中时，都市和其他玄幻流派的 Prompt 不出现长生插件规则。

插件不是作者复刻器，也不是事后润色替代品；它是生成前的风格与节奏约束层，事实、一致性和安全门禁仍由系统负责。
