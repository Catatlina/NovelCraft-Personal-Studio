## 四、未直接执行的动作及原因

以下按钮均已在页面中定位并检查可用/禁用状态或确认路径，但没有直接执行：

- 创作向导“开始生成小说”
- 榜单候选“生成小说”
- 书库“续写一章”“批量生成”
- 编辑器“整章重写”“按全部建议润色”“按全部建议改写”“去 AI 味”实际应用
- 批量删除、删除书籍、回滚/应用会改变正文的确认动作

原因是这些操作会产生真实 Provider 费用、创建或批量修改内容，部分还不可逆。已执行一次有边界的真实续写和一次真实场景分镜，且对续写结果只做预览后放弃，保留用户数据不变。
