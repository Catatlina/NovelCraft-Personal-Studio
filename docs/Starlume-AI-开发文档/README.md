## 2. 文档优先级

发生冲突时依次采用：

1. 用户最新明确指令；
2. `AGENTS.md` 与本目录的 05 号规范；
3. 本目录 PRD、架构、门禁和实施方案；
4. `docs/AI_HANDOFF.md`、`docs/REQUIREMENTS_TRACEABILITY.md`、`docs/KNOWN_ISSUES.md` 的当前快照；
5. `docs/NovelCraft-开发文档/` 中保留的历史资料。

历史资料只用于追溯，不得覆盖现行产品方向。

## 3. 命名规则

- 对用户展示的唯一产品名是 **Starlume AI**。
- GitHub 主仓库使用 `starlume-ai-studio`。`Catatlina/starlume-ai` 已被另一套历史 Express/SQLite 项目占用，因此不覆盖、不删除、不改写该仓库。
- `NOVELCRAFT_*` 环境变量、`novelcraft` 数据库名、旧事件名和本地目录名暂作为兼容标识保留。未经迁移和回滚验证，不做机械替换。
- 历史提交、备份名、迁移标识、旧文档标题中的 NovelCraft 不改写；新文档和新用户界面不得继续使用旧品牌。

## 4. 当前状态边界

- 本目录描述的是已经确认的产品目标和开发契约。
- 文档落库不等于对应产品功能已经实现。
- 人工主导创作工作流、统一创作圣经、多AI角色编排、真实码字账本和平台定稿适配器当前仍需按 03 号路线实施。
- 现有编辑器、真实 Provider 网关、V7 上下文/审阅/连续性和发布准备能力应优先复用，不能另起一套平行系统。
